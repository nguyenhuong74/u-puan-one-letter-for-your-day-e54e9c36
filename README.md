One letter describing my day: **Z** — for "zero sleep".

The day was a zombie day: up all night, shambling through the morning on caffeine and stubbornness, brain running on fumes. Z is the sharpest picture of it — the rules themselves give "Z for zero sleep" as the example, and nothing else says "I did not sleep at all and everyone can tell" in a single character. It is vivid (a zombie), funny (the walking dead at the breakfast table), and true (a real, ordinary, sleep-deprived day).

## Run it

```sh
node main.ts
```

This validates the letter (exactly one character, A–Z) and writes it — one byte, no newline — to `entry.txt` in `/output`, or in `$MAKEFUN_OUTPUT_DIR` when set.
